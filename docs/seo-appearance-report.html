✗ 仍存在的缺口

項目狀態說明 / 建議
/news 首頁未在地化✗ 新發現分類頁/文章頁皆已在地化，但 /zh/news 與 /en/news 首頁仍用靜態中繼資料：/en/news 標題仍是中文、canonical 指向無語言碼的 /news、且無 hreflang。建議把首頁改成 generateMetadata(locale)，比照分類頁產生在地化 title + 各語 canonical + hreflang。
Image license metadata✗ 可做了v1 時因封面多為第三方、版權不明而擱置。現在自產封面是我們自有版權，建議對 AI 生成圖的 ImageObject 補 license / creditText / creator / acquireLicensePage，爭取 Google 「可授權圖片（Licensable）」標章。
Speakable✗新聞可選配（語音助理），效益有限，可延後
